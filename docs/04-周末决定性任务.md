3. **确定了首选标的 = TSLA**（休市点差最宽 31.79 bp、转换幅度最大）
4. **告警一个必须建模的风险**：点差在开盘瞬间塌缩 93%，**如果挂单在塌缩前没成交，机会窗口就关闭了** → 成交时点必须建模（F6）

## 4. 宿主交接（**必须做**，否则周一没有数据）

沙箱后台进程会随本次会话结束而终止。**要拿到完整的周末样本，必须在你自己的终端常驻一份。**

### 启动（在 `D:\bitgetS2_factory_trading` 下）
```powershell

python spread_sampler.py --loop --interval 60

# 想让它在你退出终端后继续跑
Start-Process -WindowStyle Hidden python -ArgumentList "spread_sampler.py","--loop","--interval","60" -WorkingDirectory "D:\bitgetS2_factory_trading"
```

### 检查（**按固定节点看，不要盯屏**）
```powershell
Get-Content data\spread\_heartbeat.json          # 轮数/行数/错误数/最后时间
(Get-Content data\spread\2026-09-13.csv | Measure-Object -Line).Lines   # 行数应持续增长
```

### 安全设计（已内置）
- **单实例锁** `data/spread/.sampler.lock`：防止两个实例重复写同一 CSV；锁超过 6 小时自动接管
- **追加写、按 UTC+8 日期分区**：一个休市周期落在一个文件
- **网络失败不中断**：单标的失败只记 warning，继续下一轮
- **无自检循环**：除固定 60 秒采样节奏外没有任何后台循环（符合你的约束）
- **仅标准库**：不依赖 pandas/numpy，规避 Python 3.14rc 的 wheel 缺失风险

### 停止
`Ctrl+C`（会打印汇总并释放锁）。若异常退出留了锁，删 `data/spread/.sampler.lock` 即可。
