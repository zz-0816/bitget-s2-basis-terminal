## 三、⚠️ 三条必须上报的硬约束

### 3.1 永续腿的盘口深度是真正的瓶颈（实测）

休市时段 10 个配对的永续**顶部盘口深度（min(bid, ask) 名义值）**：

| 标的 | 永续顶部深度 | 永续 24h 量 | 现货/永续 量比 |
|---|---|---|---|
| SOXL | $798.36 | 58,433,212 | 49.5× |
| NVDA | $434.31 | 6,234,202 | 1,765× |
| AAPL | $213.37 | 5,156,937 | — |
| SPY | $122.54 | 611,480 | **41,173×** |
| QQQ | $78.75 | 4,009,206 | — |
| MRVL | $59.22 | 5,282,408 | 449× |
| HOOD | $58.45 | 1,262,403 | 838× |
| GOOGL | $50.98 | 5,283,268 | 1,031× |
| TSLA | $25.61 | 12,776,364 | 450× |
| **META** | **$6.49** | 1,415,098 | 5,143× |

**结论**：**永续顶部深度仅 $6 – $798**。这意味着按当前盘口，单笔只能在**数百美元**量级成交而不显著吃穿价格。
→ **策略的容量上限由永续腿决定，而非现货腿。** 报告里必须明确写出容量约束，否则是过度承诺。

**待 A 周日补测**：美股开盘后（流动性最好的时段）永续深度是否显著改善。若开盘时段深度大幅提升，则策略应限定在开盘窗口执行；若始终如此，则策略只能定位为**小规模验证**，需在报告中如实声明。

### 3.2 基差方向在所有标的与所有时点一致

10/10 配对基差为负（永续系统性高于现货），范围 **−7.4 ~ −27.8 bp**。方向统一 → 交易方向唯一（多现货 / 空永续）。
在采样窗口内基差从约 −27 bp 收敛至约 −15 bp，与"开盘收敛"一致。

### 3.3 `usdtVolume` 字段对部分符号不可信

`RSPYUSDT` 在同一分钟内既显示 251 亿（全市场第 1）又显示 5,265 USDT；`RQQQUSDT`、`RAAPLUSDT` 同样异常（现货/永续量比算出 0.0）。
→ **标的筛选禁止只依赖这一个字段**，须与盘口深度交叉验证（OQ-7 官方清单核对仍然必要）。

## 四、项目框架说明

### 4.1 后端（`server/app.py`，仅标准库）

| 端点 | 用途 |
|---|---|
| `/api/health` | 服务状态 + 当前时段（休市/盘前/盘中/盘后） |
| `/api/overview` | 每配对：两场所点差、基差、**容量约束** |
| `/api/timeline` | 基差/点差时间序列（供图表） |
| `/api/session-compare` | **分时段点差对比（休市 vs 盘中放大倍数）** |
| `/api/data-status` | 数据覆盖 + 采样器心跳（诚实标注局限） |
| `/api/meta` | 配对清单与时段标签 |

已实现：目录穿越防护、实时行情 15 秒缓存、分场所字段差异自动处理。

### 4.2 前端（`web/`，原生 JS + 手写 SVG）

六个区块：**主题陈述**（当前是否处于策略窗口）→ **同一标的两个场所对照表**（含容量列与「深度不足」告警）→ **基差/点差时序图**（休市窗口底纹）→ **分时段点差表**（放大倍数）→ **数据状态**（诚实标注局限）→ **交易结构图**（含"非无风险套利"声明）。

> 图表为手写 SVG，**无任何外部依赖**，评委离线打开也能渲染。

### 4.3 为什么这个 Demo 对评审有效

它把评审最该看的三件事直接摆出来：① 同一标的在两场所的点差差 100 倍；② 基差的全貌与时序；③ **容量约束（不回避短板）**。
第 ③ 点尤其重要——手册评审看"最大回撤"与"策略容量"，主动标注约束比被评委发现更有利。
