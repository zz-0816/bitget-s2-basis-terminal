## 一、30 秒定位：我们在做什么

**赛道一 Alpha Factory · 子主题①「套利」**
同一个标的（如 TSLA）在 Bitget 上存在于**两个场所**：rToken 现货 `RTSLAUSDT` 与美股永续 `TSLAUSDT`。
休市时段两者间存在稳定的跨场所基差；现货点差宽、永续点差窄。
策略 = **在平台「所内撮合」窗口内，现货腿挂单（赚点差）+ 永续腿对冲（吃单）**。

**基差口径（全项目唯一）**：
```
basis_bp = (永续 / 现货 − 1) × 10000       正 = 永续升水
```
