## 1b. 发帖前请先读：一条**方法学提醒**（09-19 新增）

`docs/15` 里那个"所内点差是直连的 **2.03 倍**、差异**只能归因于 route**"的对照，
在本次核对时发现**不能按因果表述**。查证过程（可复跑）：

```powershell
python tools\route_compare.py --days 99
python tools\route_compare.py --days 3
```

`route_of()` 是**时间的确定性函数**，两条 route **天然不重叠**（实测 09-12~09-20）：

| route | 时间表（UTC） |
|---|---|
| `in_house` | 周六 00:00 → 周一 00:00（周末/节假日） |
| `stockroute` | 周一 00:00 → 周六 00:00（工作日） |

于是"同 `session=closed` 比 route"实际比的是**周末的隔夜**与**工作日的隔夜** ——
**route 与"星期几/市场状态"完全共线，无法分离**。逐日拆开看得很清楚
（`session=closed`、现货全幅点差）：

| 日期 | in_house | stockroute |
|---|---|---|
| 09-12 / 09-13 | 有报价（中位 12.34 / 8.23） | **无报价** |
| 09-14 | 3.92 | 3.61 |
| 09-15 ~ 09-18 | **无报价** | 中位 2.44–3.02 |
| 09-19 | 1.92 | **无报价** |

**同一天里能比的只有 09-14（route 切换的边界日）**，而那天是 **3.92 vs 3.61 = 1.09×**。

所以：

* ❌ 不要写"所内点差是直连的 2.03 倍，差异只能归因于 route"（因果表述，数据不支持）
* ✅ 可以写"**周末所内窗口**的现货点差中位 X bp，**工作日隔夜直连** Y bp" ——
  这是"你能选的**两个时段**"的对比（描述性），**不是**纯路由效应
* ✅ 而"策略只在周末可做"这个**结论仍然成立**，但它的依据是**费率机制**而非点差统计：
  `docs/09` 引平台规则 —— 工作日走 StockRoute 时**挂单也按 Taker 计费**，
  maker 返佣仅在所内撮合期间生效。**这条与点差无关，是硬规则。**

> 本篇转发贴因此**没有**把 2.03× 当作因果证据来用：只写了"34% 且只在周末所内窗口成立"，
> 而把"为什么只在周末"归给**工作日挂单算 Taker**（机制，可引用原文）。

## 3. 线程版（7 条 —— 建议用这一版，信息密度最高）

**1/7** 我们研究 rToken 现货（`RNVDAUSDT`）与美股 USDT-M 永续（`NVDAUSDT`）
之间的跨场所价差。321 个 RWA 永续里有 **213 个**存在可配对的现货 rToken。

**2/7** 第一个坑：**盘口没有历史接口**。K 线能回补，bid/ask 不能。
所以点差、深度、成交全部靠我们自己常驻采样（4 个采样器）。
漏一分钟就是永久丢失 —— 我们已经因此记了两次事故（8.04 小时 + 74.9 分钟）。

**3/7** 第二个坑：有两个**互不等价**的时段口径，差约 4 小时。
`session`（美东）决定点差宽窄；`route`（平台）决定挂单能不能省点差。
**工作日走直连时，挂单也按 Taker 计费** —— 所以"挂单省点差"只在所内撮合窗口成立。

**4/7** 对照组拿到了（同为美股休市，只差 route）：
现货点差中位 **7.34 bp（所内）vs 3.61 bp（直连）= 2.03 倍**；
越过往返成本门槛（**11.34 bp**，已扣资金费收入）的时间占比 **38.4% vs 13.2% = 2.9 倍**。
这是"策略只能周末做"的正面证据。

**5/7** 但我们没有停在"点差够宽"。**挂单真的会成交吗？**
我们自采逐笔成交，用"成交价是否打到我们的挂单价"做观测判定：
现货腿成交率 **0.5%–86.5%**（且与点差宽度**反向**），逆向选择中位 **−0.21 ~ −21.84 bp**。
→ **能挂单的时段 ≈ 点差不够；点差够的标的 ≈ 没量。**

**6/7** 更进一步，我们量了**两条腿的联合分布**（不是各自成交率的乘积）：
`P(两腿都成交) = 0.70%`，**`P(只成交一腿) = 24.9%`**，`P(都没成交) = 74.4%`。
**单腿裸露才是主要风险形态，不是两腿都成交。**
（顺带修掉一个口径错误：旧写法把两个"按成交笔数"的率相乘，分母根本不是一回事。）

**7/7** 我们也如实报告执行状态的变化：现货腿 **09-14~09-18 零成交**（报价仍在刷新），
**09-19 06:46 UTC 恢复成交，且恰好落在 `in_house` 窗口内**（`docs/29` §5）。
以及一条监管事实：SEC 于 09-17 对代币化美股交易场所给予**临时、有条件豁免**，
并临时豁免 AMM 流动性提供者的自营商认定 —— 我们的做市行为落在该豁免认可的范围内，
但豁免**附条件、5 年到期、且正在征求意见**。
