## 🔴 报告里必须写对的一件事：**两条轴分开声明**

这是 `tools/sample_adequacy.py` 得出的结论，**写错会被评委一眼看穿**：

```
收益回测：1h 面板（58–65 天）                    ← 满足 ≥60 天门禁
成本参数：2026-09-12→09-14 in_house 窗口实测标定  ← 仅 2.07 天、1 个周末
```

**绝不能写成「用周末样本跑了 60 天回测」** —— 盘口没有历史接口，2.07 天就是全部。

**必须主动写的局限**（`docs/18` §6 已列全，7 条）：永续 1H 仅 58 天、
容量瓶颈在现货腿、窗口内 13–17 小时不可回补缺口、样本内非样本外、
资金费 74.2% 结算点为 0、`indexPrice` 与原生股价差 2.8%（开放问题）、盘口不可回补。

⚠️ **有一条不要写**：我们曾声称「rToken 跟踪偏离 −33~+85 bp」，
**已撤回**（实测中位 +1.7 bp）。写进去会变成硬伤。见 `docs/14` §4.2。
