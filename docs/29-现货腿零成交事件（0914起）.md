## 0. 一句话

**不是采样器漏采，也不是我们的代码问题** —— 上游 `R*USDT`（rToken 现货）

但**报价仍在正常刷新**（09-17 现货点差中位 1.86 bp）。
→ 这是一个**只有报价、没有成交**的市场状态，已持续 **4 天**。

## 2. 这对已有结论意味着什么

| 受影响的结论 | 影响 |
|---|---|
| **双腿联合成交分布**（`docs/14` §9） | 只能测 **09-12~09-14**（现货成交带的最后三天）。之后的日子"两腿都成交"恒为 0 —— 那不是"相关性变化"，是**测不到** |
| **"只成交一腿" 24.9%** | 这是**三天样本**的数字。若当前状态持续，现货腿的实际成交率是 **0**，`P(只成交一腿)` 会**更高**（= 永续腿单边成交），腿风险比报告里写的更差 |
| **可捕获名义额 $1.4k–$125k**（`docs/13`/`docs/14`） | 来自**盘口深度**，不是成交额。报价还在 → 这个数仍然"算得出来"，但**没有成交量支撑**，实际可捕获性存疑 |
| **"现货腿是容量瓶颈"** | 结论**更强**了：不是"成交额小"，而是**根本没有成交** |
| 项目二的执行建议 | 现货腿"挂单成交"这条路径在 09-15 之后**无法成交**；模型因此在 `stockroute` 分层取到的 `P(现货)≈0.03%` 其实**低估了严重性**（真实值是 0） |

⚠️ **不要**把这条读成"策略更好了"。零成交 = 挂单永远不成交 = **赚不到点差**，
而不是"没有逆向选择风险"。挂单策略的收益来源就是成交。

## 3. 尚未结论的部分（诚实标注）

1. **原因未知**：是 rToken 做市商撤了、发行方暂停、还是要下架？
   我们只查了成交接口与状态文件，**没有**去查公告（`bitget-signal` 的
   `news-briefing` 可以查，但需要人工读公告，属于下一步）。
2. **是否可恢复未知**：4 天零成交既可能是临时，也可能是终局。
   08-22 起的历史里有连续多日成交（`trades-2026-08-22`~`09-14`），
   所以至少说明**这个市场曾经是活的**。
3. **永续侧不受影响**：永续成交一直正常（09-17 有 38 万笔），
   基差、资金费、执行成本这些**永续侧**结论不受本条影响。
4. **对"窗口"口径的影响**：`in_house` 是周末窗口，09-19（周六）会再开一次；
   到时可以复检现货是否恢复成交 —— **这是最近的一次观察点**。
