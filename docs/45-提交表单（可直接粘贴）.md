```
【第一段 · 思路】

代币化美股（rToken）让美股敞口做到 7×24，对应的美股永续合约同样是 7×24，但两条腿在不同时段由不同机制定价：周末与节假日走平台「所内撮合」，工作日走「StockRoute」直连美股。Bitget 现有 321 个 RWA 永续合约，其中 213 个存在可配对的 rToken 现货。我们研究的问题是：这个价差在哪个时段、以什么方式，才真的能被散户执行掉。

信号来源：同一标的在「rToken 现货」与「美股 USDT-M 永续」之间的基差，全项目统一口径 basis_bp =（永续/现货 − 1）× 10000，正 = 永续升水。关键结论来自一次自我否证——我们实测发现 taker 路线被点差吃穿：往返 taker 手续费 22.0 bp，而现货全幅点差中位仅 7.34 bp，单纯吃单在结构上不可能盈利。据此转向 maker 后解出费用门槛：现货全幅点差须 ≥ 13.70 bp（四条腿全挂单），扣掉资金费收入后为 11.34 bp。

决策逻辑：开仓条件 = 平台路由为所内撮合 且 basis_bp ≥ 11.34；平仓 = 基差 ≤ 0 或持满 48 小时或窗口结束；方向 = 多 rToken 现货 / 空美股永续。收益恒等式为 PnL =（基差收敛）+ 两腿价位优势 + 资金费收入 − 手续费。这个恒等式本身就是核心认知：基差平稳时收敛项期望为 0，所以本策略赚的不是"价差必然收敛"，而是流动性提供的补偿减去逆向选择——这一点决定了策略必须定性为做市。

风控四层，全部落在代码里：① 费用门槛——只在点差足够宽时开仓，门槛由实测费率解出而非拍脑袋；② 事件闸门——财报/宏观事件窗口内禁止挂单（硬规则），闸门不可用时降级为 caution，绝不静默放过；③ 双腿腿风险——两腿都成交才算建仓，只成交一腿即裸露敞口，成交概率用实测联合分布而非独立性假设；④ 双档检验——每个结论同时给中位档与悲观档（P75 点差），两档都过才算通过。

【第二段 · 目标用户与产品价值】

目标用户：已在 Bitget 持有 USDT、同时接触 rToken 现货与美股合约的小型量化散户（1,000–100,000 USDT），而非泛散户群体。泛散户由配套的「执行成本感知」工具服务——该工具告诉他们休市时段市价单的真实代价，并引导其改用限价单。我们不做"稳赚"承诺；本策略承担方向与逆向选择风险，属做市型价差捕获，非无风险套利。

画像落到四个维度：人群定位为 Retail 偏 Pro（会写脚本、已在多平台有仓位）；资金规模 1,000–100,000 USDT；风险偏好中低（赚流动性补偿、不做方向，但承担逆向选择与腿风险）；交易频率低——只在周末/节假日窗口开仓，平均持仓 13.0 小时，样本期内约 9 个周末可交易；主要市场与场景为 Bitget rToken 现货 × 美股 USDT-M 永续，场景即美股休市期的所内撮合窗口。

为什么是这群人（实测依据）：这批 rToken 单笔成交额中位仅 12–294 美元，对手方本身就是散户级；现货腿顶部挂单深度只有 11–34,947 美元。这是一个小额可参与的市场，不是机构市场；同时策略需要持续挂单与双场所同时管理，因此目标用户是"会写脚本、已在多平台有仓位"的小型量化散户。

产品价值：把「休市期的价差」从看起来有，变成知道什么时候真的有、以及该怎么拿。交付三件事：① 可执行的费用门槛；② 哪个时段可做的时间覆盖率；③ 每一单的执行方式与条件点位（吃还是挂、挂哪个价、规模上限）。

【第三段 · 验证数据与关键指标】

回测（1h 面板，仅 in_house 窗口，entry=11.34 / exit=0 / max_hold=48h）：测试区间 2026-07-18 → 2026-09-19，总期 65.4 天（in_house 子集 63.7 天），10 个 in_house 周末窗口；交易 210 笔；总收益 +5,678.21 bp；年化 Sharpe 3.78（bar 级口径，见下）；年化 Sortino 3.70；最大回撤 290.46 bp；胜率 81.9%；换手率 5.58%；均笔收益 +27.04 bp（中位 +18.57）；平均持仓 12.6 h；t 统计量 8.31。对照无门槛基线（299 笔 / +5,199.15 bp / Sharpe 3.37 / MaxDD 345.80 bp / 胜率 70.6%），门槛的引入让四项同时改善：收益 +9.2%、Sharpe +12%、最大回撤 −16%、胜率 +11.3pp。
```
