## 2. 根因（两件事叠加，缺一不可）

### 2.1 直接原因：代理断掉 → 采样器 SSL EOF 退出

`data/logs/sampler_core.err.log` 的最后写入时间是 **09-20 02:47:33（本地）= 09-19 18:47 UTC**
—— 与数据停写的时刻**完全吻合**。尾部内容是同一形态的错误刷屏：

```
[warn] spot RMRVLUSDT: URLError(SSLEOFError(8, '[SSL: UNEXPECTED_EOF_WHILE_READING] ...'))
[warn] perp MRVLUSDT:  URLError(SSLEOFError(8, '[SSL: UNEXPECTED_EOF_WHILE_READING] ...'))
[warn] spot RTSLAUSDT:  URLError(SSLEOFError(8, '[SSL: UNEXPECTED_EOF_WHILE_READING] ...'))
[warn] perp TSLAUSDT:   URLError(SSLEOFError(8, '[SSL: UNEXPECTED_EOF_WHILE_READING] ...'))
```

这和 **09-18 那次**（`docs/27`）是同一个签名：**代理节点挂了**。直连被 ISP SNI 阻断
（`WinError 10054`），所以代理是唯一通路。

### 2.2 🔴 真正的系统性原因：**没有任何东西会把它们拉起来**

| 环节 | 状态 |
|---|---|
| 守护进程（`sampler_supervisor.ps1`） | **早就死了** —— `data/logs/supervisor.log` 最后一条是 **09-17 02:21:57** |
| 开机自启计划任务 `BitgetS2_SamplerGuard` | **不存在**（`Get-ScheduledTask` 里查不到） |

所以：守护 09-17 就没了 → 没人监控采样器 → 代理在 09-19 18:47 一断，四路一起退出
→ **躺了 12 小时没人知道**。

> 这才是要修的东西。代理会再断（它已经断过两次），但**断 5 分钟和断 12 小时的区别，
> 就在于有没有守护和自启**。


结果（恢复后复核）：

|---|---|---|
| spread | 1 | 滞后 2.1 分钟 |
| orderbook | 1 | 滞后 0.6 分钟 |

| universe | 1 | 滞后 3.1 分钟 |

`check_samplers.py --json` → `{"healthy": true, "issues": 0}`

### 3.2 让它不再发生（已完成，且**验证过不会拉出第二套**）

`install_sampler_guard.ps1` 注册计划任务需要管理员权限 → **被拒**，它自动回退到
启动文件夹（`Startup\BitgetS2_SamplerGuard.cmd`，登录时启动）。
但那**只覆盖登录时刻** —— 长时间登录期间守护若挂掉仍无人拉起。所以另外用

```powershell
schtasks /Create /TN "BitgetS2_SamplerGuard_Min" /SC MINUTE /MO 10 /F `
  /TR 'powershell.exe -ExecutionPolicy Bypass -NoProfile -WindowStyle Hidden -File "...\scripts\sampler_supervisor.ps1"'
```

**每 10 分钟**跑一次守护。安全性来自守护自身的单实例锁：
**已有守护存活 → 新实例立刻退出**，不会出现"两个守护各拉一套采样器"
（那正是 `sampler_supervisor.ps1` 头部警告过的、会导致同一 CSV 被交错写入的坑）。

**实测验证**（手动触发一次任务）：

```
触发前：spread=21024 ｜ universe=21412 ｜ orderbook=8424 ｜ trades=25548
触发后：spread=21024 ｜ universe=21412 ｜ orderbook=8424 ｜ trades=25548   ← PID 未变
守护日志：没有新增"守护进程启动"条目                                 ← 第二次守护自己退出了
```

✅ 幂等、不重复。三层防线的最终形态：

```
登录 → 启动文件夹拉起守护
每 10 分钟 → 计划任务再拉一次（已有守护则空跑）
守护存活期间 → 采样器退出后 10 秒自动重启
```
