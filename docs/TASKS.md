### ⭐⭐ 关键问题：这次周末样本**能不能**作为策略运行测试的基础？

> 用户明确问的就是这个。**"采样达标率 79.9%" 回答的是采集质量，
> 不是"能不能用来测策略"** —— 两者必须分开。工具：`tools/sample_adequacy.py`

**答案：可以用于「成本模型 + 微观结构」标定，但\*\*不能\*\*单独作为收益回测/样本外衰减的基础。**

原因是策略测试需要**两条独立的时间轴**，它们的达标情况完全不同：

| 轴 | 数据源 | 实际跨度 | 门槛 | 判定 |
|---|---|---|---|---|
| **价格轴** | 1day 面板（213 配对） | **221.0 天** | ≥60 天 | ✅ |
| **价格轴** | 1h 面板（10 配对） | **58.4 天** | ≥60 天 | ⚠️ 刚好差一点（到 09-21 会到 65+ 天）|
| **价格轴** | 5m 序列（10 配对） | 13.9 天 | — | 只够细粒度校准 |
| **成本轴** | 盘口（点差/深度） | **2.07 天** | — | ✅ 够标定 |
| **制度覆盖** | `in_house` 周末数 | **1 个** | 越多越好 | ❌ **n=1** |

**⚠️ 最关键的一条：盘口只有 2.07 天，其中 `in_house` 只有约 40 小时、且只有 1 个周末。**

| 用途 | 判定 | 依据 |
|---|---|---|
| 成本门槛标定（11.34 bp） | ✅ | in_house 现货报价 n≈23,019 / 约 40 小时 |
| 点差分布（中位/P75/P90） | ✅ | 同上；但**不含周间方差** |
| 逆向选择量化 | ✅ | 逐笔成交 ∩ 盘口 = 仅 ~1.9 天 |
| 容量 / 5 档深度 | ✅ | orderbook 697,460 行 |
| 成交判定 | ✅ | trades 118,461 笔 |
| route 对照 | ✅ | 同 session 干净对照 2.03 倍 |
| **60 天总期回测** | ⚠️ 只能用 1h 面板 | **盘口覆盖不了 60 天** |
| **样本外 30 天衰减** | ❌ **不能靠周末样本** | 周末制度 n=1 |
| **跨周末稳健性** | ❌ | n=1，无法估计周间方差 |
| **按标的的稳定结论** | ❌ | AAPL 的 +34bp 来自 30 笔 / $1,558 |

**→ 报告里的正确写法（两条轴分开声明）：**

```
收益回测：1h 面板（58–65 天，随日期增长）          ← 满足 ≥60 天门禁
成本参数：本次 in_house 窗口的实测标定（n=1 个周末）← 如实说明
```

🔴 **绝不能写成「用周末样本跑了 60 天回测」** —— 那是不成立的，
且是评委最容易一眼看穿的漏洞。**盘口没有历史接口，2.07 天就是全部。**

### 方式 1：网页（最简单）

1. 打开 https://github.com/zz-0816/bitget-s2-basis-terminal/settings/access
2. 点 **Add people**
3. 输入对方的 **GitHub 用户名 / 邮箱 / 全名**
4. 选角色：
   - **Write** — 可推送代码、管理 Issue/PR（**日常协作用这个**）
   - **Maintain** — 可管理仓库设置（不含删除/转移）
   - **Admin** — 完全控制（**谨慎给**）
5. 点 **Add … to this repository** → 对方会收到邮件/通知，**接受后生效**

### 方式 2：命令行

```powershell
# 邀请为 Write 权限
gh api -X PUT repos/zz-0816/bitget-s2-basis-terminal/collaborators/<对方用户名> -f permission=push
# permission 取值：pull(只读) / triage / push(写) / maintain / admin
```

一行脚本（本仓库已提供）：
```powershell
powershell -ExecutionPolicy Bypass -File scripts\invite_collaborator.ps1 -User <对方用户名> -Permission push
```

### 注意事项

- **仓库 Owner（你）无需邀请**；协作者需**接受邀请**后才生效
- 若对方是**免费账号**：公开仓库的协作者数量不限；**私有仓库**免费额度有限
- 邀请发出后可在同一页面看到 `Pending invitation`，可随时取消
- 需要对方**先有 GitHub 账号**；邮箱邀请会给他发注册/绑定链接
