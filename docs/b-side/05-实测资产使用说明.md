## 二、数据规格（本机实测）

| 数据 | 文件数 | 记录数 | 时间区间（UTC） |
|---|---|---|---|
| `RTSLAUSDT-1h-part*.json` | 18 | **3600 根** | 2026-03-12 21:00 → 2026-09-11 15:00 |
| `RNVDAUSDT / RAAPLUSDT / RHOODUSDT / RMETAUSDT / RQQQUSDT -1h-part*` | 各 10 | 各 2000 根 | — |
| 原生股日线 `TSLA/NVDA/AAPL/HOOD/META/QQQ-日线.json` | 6 | 各 **128 个交易日** | 2026-03-11 → 2026-09-11 |

**结构说明**：

- **Bitget 1h 线**：顶层 `{code, msg, requestTime, data}`，`data` 是数组，每行
  `[ts_ms, open, high, low, close, baseVol, quoteVol, quoteVol]`，**时间戳是毫秒**
- **原生股日线**：**Yahoo `chart` 结构** —— `chart.result[0].timestamp`（**秒**）+ `indicators.quote[0].{open,high,low,close,volume}`
  （注意与 Bitget 格式完全不同，且**两个源的时间戳单位一个是毫秒一个是秒**）
- 60 天回测窗口（30 IS + 30 OOS）**绰绰有余**

## 三、怎么跑

### 3.1 通道一：Windows 原生 Python + 本地 HTTP 代理（**本机已实测通过**）

```powershell
$env:HTTP_PROXY  = "http://127.0.0.1:7877"
$env:HTTPS_PROXY = "http://127.0.0.1:7877"

# 先把 $W 换成本仓库在你机器上的目录（例：D:\hackathon\bitget）
$W = "<工作台>"

# 单次采样
& python "$W\实测\03-盘口采样器.py"

# 常驻采样（按 02 §3.1 要求每 60 秒一次）
& python "$W\实测\03-盘口采样器.py" --loop --interval=60
```

- 产出：脚本同目录下 `盘口采样.csv`，**追加写、不覆盖**
- 列：`utc_time, symbol, last, bid, ask, spread_bp, bid_sz, ask_sz, vol24h_usdt`
- ⚠️ **端口是 `7877` 不是 `7890`** —— 本机 `7890` 已不在监听（见 `04` §3.1）
- ⚠️ 如果所在会话注入了别的代理环境变量，**显式覆盖**它（本机遇到过注入 `60717` 导致 SSL EOF）

### 3.2 通道二：WSL（**同样实测通过**）

```powershell
wsl -- bash -lc "cd '/mnt/d/<你的路径>/Bitget黑客松/实测' && python3 03-盘口采样器.py --loop --interval=60"
```

- WSL 发行版：**Ubuntu-24.04**（本机，状态 Running）
- 若中文路径被命令行吞掉（Git Bash → `wsl.exe` 有这个坑），改为先 `wsl` 进去再 `cd`，或把命令写进 `.sh` 文件里执行
- 重抓数据：`wsl -- bash -lc "cd '/mnt/d/<你的路径>/Bitget黑客松/实测' && bash 01-抓取数据.sh"`

### 3.3 跑检验（复现 `检验输出.txt`）

```powershell
$W = "<工作台>"     # 同上，换成实际目录
& python "$W\实测\02-检验.py"
```

## 五、`检验输出.txt` 已经能支撑哪些结论

这份输出本身是一份**可引用的取证材料**，直接对应 `01` 的需求条目：

| 输出节 | 已得结论 | 对应需求 |
|---|---|---|
| 【1】收盘同步性 | 6 标的平均绝对偏差 **0.013%–0.036%** → **无系统性平台溢价** | 支撑 `01` §1「原说明 vs 本版」的差异表 |
| 【2】休市时段偏离 | 分**工作日盘前/盘后/周末**给出 n、均值、中位、标准差、p95、极值；并切出「噪音型 vs 事件型」 | **F0 时段标定** + **F2 回归检验**的样本基础 |
| 【3】隐含开盘 vs 真实开盘 | 相关系数 **r = 0.924–0.984**、方向一致率 **77.3%–95.3%** | 支撑 **F1**（`info` 是真的，`resid` 才可套利） |
| 【4】极端偏离个案 | 11 例全部被后续开盘证实（含 4/8 报 +4.95% → 真实 +4.94%） | 支撑「反向交易＝接刀」的论断 |
| 【5】反向 fade 假设回测 | 毛利 **≈0.1% 量级**、各标的**符号不一致**；附**成本敏感度表**（0.02%→+0.095%、0.20%→−0.085%） | 支撑 **F4 成本模型**与「毛利不足以覆盖成本」 |
| 【6】流动性 | 交易时段 vs 周末 **倍差 1211×–4588×** | **F3 / F11** 的成本约束 |
| 【7】回归速度 | 偏离越过 \|1%\| 后回到 \|0.3%\| 以内：**盘前中位 10 小时、盘后 2 小时、周末 6 小时** | **F2** 的半衰期素材 |

> **注意**：`02-检验.py` 的样本区间（2026-03~09）**全程处于美国夏令时**，脚本按 `13:30–20:00 UTC` 处理交易时段；**冬令时必须改成 `14:30–21:00 UTC`** —— 这正是 `01` §3 讲的 N6 DST 陷阱，目前**尚未被这套检验覆盖**。

## 六、用之前必须知道的五个坑

| # | 坑 | 说明 / 怎么办 |
|---|---|---|
| 1 | `01-抓取数据.sh` **会先删再抓** | 它用 `rm -f "$RAW/$RT-1h-part"*.json` 清掉旧分页再重下。**跑之前先把 `原始数据\` 备份一份**，否则现有 3600 根 RTSLA 快照会被"截至今天"的新数据替换 |
| 2 | 脚本内路径是**自定位**的 | 三个脚本都用 `$0` / `__file__` 定位自己所在目录 → **复制到新位置可直接跑**；只有**顶部注释里的示例路径**需要按你自己的挂载点替换，不影响执行 |
| 3 | 采样器默认间隔 **3600 秒** | `01`/`02` 要的是 **60 秒**。必须显式加 `--interval=60`，否则一小时才采一次，捕不到点差分布 |
| 4 | `02-检验.py` **只用收盘价** | 点差是未知量（脚本自己的待办也这么写）。**成本模型不能靠它**，要靠 `03-盘口采样器.py` 的采样 |
| 5 | 原生股日线的**时间戳单位是秒** | rToken 是毫秒。两源混用时这个单位差异是最容易出的静默 bug |
