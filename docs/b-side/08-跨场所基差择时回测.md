## 0. 一句话结论

**在 9 个 `in_house` 周末窗口（1h 面板 58 天）上，策略全部为正收益，样本外衰减 `decay = 0.896`
（门槛 ≥ 0.5）—— 门禁通过。**
但**收益结构与甲侧 `docs/14` 的定性不同**：主要来源是**基差择时（+29.4 bp/笔）**，而不是做市点差补偿
（+15.5 bp/笔）；且**按现货腿成交率折算后，收益只剩 26%，标的排名完全反转**。

## 1. 数据与「两条轴」（严格分开声明）

`tools/sample_adequacy.py` 的结论是硬约束，本回测严格遵守：

| 轴 | 数据 | 覆盖 |
|---|---|---|
| **收益轴** | `data/panel/1h_10pairs.csv` 的 `in_house` 子集 | **58.4 天 / 10 配对 / 3691 bar / 9 个周末窗口** |
| **成本轴** | `data/derived/friction_budget.csv` + `funding_rates.csv` | 2026-09-12 → 09-14 盘口实测（**仅 1.9 天、1 个周末**） |

> ⚠️ **绝不能读成「用周末样本跑了 60 天回测」**。收益轴是 1h 面板，成本轴才是那 1.9 天。

**窗口定义**：`in_house` = 周六 00:00 UTC → 周一 00:00 UTC（= 北京 周六 08:00 → 周一 08:00）。
归组算法 = 「该时刻之前最近的周六 00:00 UTC」，得到 **9 个独立窗口**：
`07-18 / 07-25 / 08-01 / 08-08 / 08-15 / 08-22 / 08-29 / 09-05（含 88h 长假）/ 09-12（残缺，16h）`。

> 📌 **这比盘口数据强得多**：盘口只有 **1 个周末**（n=1，无法估周间方差），
> 而 1h 面板提供 **9 个周末** —— 本回测能给出**周间一致性证据**，这是现有文档里没有的一层。

## 2. 策略定义（参数显式、可复现）

每个 `in_house` bar：

```
空仓 且 basis_bp >= entry_thr                                    -> 开仓
持仓 且 (basis_bp <= exit_thr 或 持满 max_hold 或 窗口结束)        -> 平仓
```

方向 = **多 rToken 现货 / 空美股永续**（`basis_bp` 越高 = 永续越贵，越值得做）。

单笔 PnL(bp)：

```
PnL = (entry_basis − exit_basis)          # 基差收敛（basis 降 = 赚）
    + 2 x (half_spot + half_perp)         # 两腿挂单的价位优势（往返）
    + f_dmid_spot(k6) + f_dmid_perp(k6)   # 逆向选择（实测，负）
    + funding x (持有小时/48)              # 空永续收资金费
    − 14.0                                # 四条腿全挂单往返手续费
```

**只取 `in_house`**：因为 `B_maker` 只在所内撮合窗口有经济意义（工作日挂单也按 Taker）。

**设计取舍（诚实声明）**：`spot_spread_med_bp` 在面板里是**每标的一个常数**
（复算确认：AAPL 恒 27.38、GOOGL 恒 5.57 …，唯一值数均为 1），所以**逐 bar 时变的只有 `basis_bp`**
⇒ 本回测的策略维度是**基差择时**，不是点差择时。点差的时变分析属于**成本轴**（甲侧 docs/14）。

## 3. 主结果（B18 五指标）

| 指标 | entry=0（不做择时） | **entry=11.34（成本门槛）** |
|---|---|---|
| 交易数 | 265 | **190** |
| 总收益 | 4475.05 bp | **5103.57 bp** |
| Sharpe（年化，bar 级） | 3.13 | **3.64** |
| Sortino（年化） | 3.29 | **3.61** |
| MaxDD | 363.82 bp | **290.46 bp** |
| 换手率 | 7.85% | **5.63%** |
| 胜率 | 70.2% | **80.0%** |
| 平均单笔 | +16.89 bp | **+26.86 bp** |
| **t 统计量（交易级）** | 6.17 | **7.61** |

**择时的价值**：entry 从 0 提到成本门槛 11.34 bp，

> ⚠️ **Sharpe 3.64 是 bar 级口径**，分母含大量「空仓期收益 0」，**会稀释方差、系统性抬高 Sharpe**。
> 更审慎的是**交易级 t 统计量 = 7.61**（190 笔，平均 +26.86 bp）——
> 它回答的是「平均单笔收益是否显著为正」，答案是**高度显著**。

| entry \ exit | 0.0（Sharpe / 总 bp） | 5.0（Sharpe / 总 bp） |
|---|---|---|
| 0.0 | 3.13 / 4475 | 3.30 / 4687 |

**平坦区**：`entry ∈ [8, 15]`、`exit = 5` 时 Sharpe 稳定在 **3.87–3.97**，无孤立尖峰。

**有意义的一点**：`exit = 5` 一致优于 `exit = 0` —— 即**不必等基差完全归零才平仓**，
回落 5 bp 就走更好（降低持仓期暴露）。

## 7. ⭐ 收益分解（**与甲侧 docs/14 的定性有张力**）

每笔平均（entry=11.34，n=190）：

| 构成项 | bp/笔 |
|---|---|
| **convergence**（基差收敛） | **+29.40** ← 主来源 |
| capture（两腿挂单价位优势） | +15.45 |
| adverse（逆向选择） | −4.69 |
| funding（资金费） | +0.70 |
| fee（往返手续费） | −14.00 |
| **合计** | **+26.86** |

### 与甲侧 docs/14 §5 **不矛盾，但互补**

> 甲侧 docs/14 写的是：**「`(B_e − B_x)` 在基差平稳时期望为 0 → 本策略赚的是流动性补偿，
> 不是『价差必收敛』」**

本回测补的是**条件期望**：

| 口径 | convergence 贡献 |
|---|---|
| **无条件开仓/平仓**（甲侧 docs/14 的口径） | 期望 **0** |
| **basis ≥ 门槛才开仓**（本回测） | **+29.40 bp/笔** |

**⇒ `(B_e − B_x)` 的无条件期望确实为 0，但「高位择时」能把它变成显著正贡献。**
证据是参数表单调：`entry` 从 0 提到 25 bp，收益先升（4475 → 5134）后降，峰值在 8–11.34 bp 一带。

> ⚠️ **但这不等于「发现了 alpha」，必须同时看第 8 节** —— 择时带来的收敛收益，
> 是在**假设挂单必成交**的前提下算出来的，而成交率恰恰与点差宽度反向。

## 8. ⭐ 成交率折算（**最贴近现实的口径，也是最重要的修正**）

甲侧 docs/14 §3.1 实测：**现货腿成交率 0.5%–86.5%，且与点差宽度反向**。
本回测的 `capture` 与 `convergence` 都**隐含「挂单必成交」**，所以必须折算：

| base | 成交率 | 笔数 | 机会 bp/笔 | **折算后 bp/笔** |
|---|---|---|---|---|
| **META** | 86.49% | 17 | 25.30 | **21.88** |
| **NVDA** | 46.87% | 29 | 34.84 | **16.33** |
| **GOOGL** | 36.35% | 21 | 29.68 | **10.79** |
| MRVL | 9.76% | 31 | 35.09 | 3.43 |
| QQQ | 20.75% | 17 | 13.00 | 2.70 |
| TSLA | 36.95% | 23 | 5.13 | 1.90 |
| AAPL | 2.98% | 21 | **51.52** | **1.54** |
| HOOD | 8.68% | 20 | 14.60 | 1.27 |
| SPY | 0.50% | 11 | 21.71 | **0.11** |
| **合计** | — | 190 | 5103.57 | **1326.60** |

**两个必须一起读的发现**：

1. **排名完全反转。** 未折算时 AAPL 最强（51.52 bp/笔）；折算后只剩 **1.54**，
   而 META（21.88）反超成为第一。**这正是甲侧 docs/14「点差宽与能成交互斥」的量化印证** ——
   本回测把这个定性判断变成了**可排序的数字**。
2. **收益量级腰斩再腰斩。** 5103.57 → **1326.60 bp**（保留 26%）。
   ⇒ **任何「策略年化 X%」的说法都必须先过这一关**；否则只是「机会收益」，不是可实现收益。

> ⚠️ 折算后是**「每笔挂单的期望收益」**。真实可实现收益还需乘以**单位时间的挂单次数**，
> 而那个量取决于我们自己的挂单强度（策略选择），不是数据能定的 —— 如实标为开放项。

## 9. ⭐ 费用敏感性：一次**被自己证伪的预测**（保留过程）

乙侧最初预判：「若永续腿改吃单（多付 8 bp），收益将全面转负」——
依据是甲侧 docs/14 §4 说「永续吃单会吞掉全部边际」。**实测证明这个预判是错的。**

`python tools/b_side_backtest_fee_sensitivity.py`（策略参数固定 entry=11.34 / exit=5.0）：

| 口径 | 交易 | 总收益 bp | Sharpe | MaxDD | 胜率 | 平均单笔 | t 统计量 |
|---|---|---|---|---|---|---|---|
| 四条腿**全挂单**（14.0 bp） | 227 | **5502.45** | 3.97 | 290.78 | 82.4% | +24.24 | 8.21 |
| 永续腿**吃单**（22.0 bp） | 227 | **3686.45** | 2.72 | 315.83 | 66.1% | +16.24 | 5.50 |

**收益保留 67%，且 8/9 标的、8/9 窗口仍为正** —— 没有转负。

### 为什么预测会错，以及这说明什么

**因为本回测的策略与甲侧 docs/14 的策略不是同一个东西**：

| | 甲侧 docs/14 的策略 | 本回测的策略 |
|---|---|---|
| 开仓依据 | **现货点差门槛**（≥ 13.7 bp） | **基差门槛**（≥ 11.34 bp） |
| 收益主来源 | 做市点差补偿（`capture`） | **基差择时（`convergence`，+29.4 bp/笔）** |
| 对费率的敏感度 | **极高**（多 8 bp 即吞掉边际） | 中等（收益池更大，8 bp 只削减 33%） |

⇒ 甲侧 docs/14 那句「永续吃单会吞掉全部边际」，**只在「纯做市点差捕获」口径下成立**；
本回测因为叠加了基差择时，收益池更厚，容得下 8 bp 的费率上升。

⚠️ **但这不构成「永续腿可以吃单」的建议** —— 见局限 7 与第 8 节的成交率折算。

## 10. 局限（**必须与结论一起读**）

1. **成交率折算用的是现货腿口径**（`precise_fill_spot_bid.csv`）。永续腿成交率 21%–57% 未纳入，
   而两腿**必须同时成交**才构成对冲；若按「两腿都成交」的概率，实际值**还会更低**。
2. **成本参数只有 1.9 天 / 1 个周末**（09-12 → 09-14 盘口），**不含周间方差**。
   而收益轴的 9 个周末里，有 8 个发生在**那段盘口之前** ⇒
   **相当于用「一个周末的成本」去标定「九个周末的收益」**。**这是本回测最需要外部复核的地方。**
3. **`capture = 2×(half_spot + half_perp)` 取的是面板里那个常数点差快照**，不是逐 bar 实测。
   面板的点差列被 `build_panel.py` 明确标注为「研究级近似」。
4. **样本内偏乐观**：IS 的 Sharpe(4.23) 高于 OOS(3.79)，且 `entry ∈ [8,15]` 的平坦区
   是**看过全部数据后**给出的；严格做法应在 IS 上选参、只在 OOS 上报告（本报告为完整起见给了两段）。
5. **09-12 窗口不完整**（16h / 130 bar），已单列，未混入主结论。
6. **未纳入财报事件闸门**（`docs/21` B14：日历 0 条，待补）。
7. **未纳入滑点/冲击**；`fee` 主口径用四条腿全挂单的 14.0 bp。
   永续腿吃单（22.0 bp）的情形见 §9 —— **实测仍为正**，故不列为「会转负」的风险。
8. **本回测的策略 ≠ 甲侧 docs/14 的策略**：前者开仓看**基差**，后者开仓看**点差**。
   二者收益来源与费率敏感度都不同（§9 有对照表）。
   **不要把本报告的 Sharpe 直接当作「甲侧 docs/14 那个策略」的绩效。**
9. **成交率折算后是「每笔挂单期望收益」，不是年化收益** —— 缺「单位时间挂单次数」这一环。

## 11. 与甲侧结论的关系（**互补，不冲突**）

| 维度 | 甲侧 docs/14（单点预算） | 本报告（乙侧，时间序列） |
|---|---|---|
| 数据 | 09-12 → 09-14 盘口（1.9 天） | 1h 面板（58.4 天 / 9 个周末） |
| 产出 | 每标的**一个数**（净 bp、门槛） | **收益曲线 + 五指标 + 参数面** |
| 结论 | 门槛 11.34 bp；只有 AAPL/SPY 过线 | **9/9 窗口正收益；entry=8–15 是平坦区** |
| 收益来源 | 流动性补偿（点差） | **基差择时为主，点差次之** |
| 一致性证据 | n=1 个周末 | **n=9 个周末（周间方差可估）** |

**两者结合才完整**：甲侧给**成本标定**，本报告给**收益分布与稳健性**。
